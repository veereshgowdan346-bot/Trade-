## 2. Button/Control Audit Findings
- **UI-001 (FIXED):** PAPER⇄LIVE toggle falsely advertised live enablement → replaced with honest badge + interlock toast. No remaining control can attempt live mode.
- Flash Test: has loading state (`flashing` disable), success/error toasts, RTT metric ✓; duplicate-click protected via `disabled` ✓.
- Resync/Watch buttons: `disabled={resyncing}` ✓ loading states present.
- `setPrimary` has success toast; error path via api throw handling (global) — acceptable.
- Confirmations: emergency actions historically gated by `confirm()`; UI-001 removed the only *misleading* confirm.
- Accessibility: buttons use text labels + `title` tooltips; aria-labels not systematically present (LOW gap).
- State sync: UI refreshes from `/api/state` after actions (`await refresh()`); SSE stream updates live ticks.
