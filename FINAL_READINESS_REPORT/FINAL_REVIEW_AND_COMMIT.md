## 4. Specific audits requested

**BT-004 (session Sharpe/Sortino).** Hand-verified: `sharpe = (mean/sd)√252` on session returns, `sd`
with `n−1`; Sortino uses `sqrt(mean(min(r,0)²))` over **all** n observations; `MIN_SESSIONS_FOR_RISK_ADJUSTED = 20`;
`<20` → `null` + `INSUFFICIENT_SAMPLE`; `EPS = 1e-12` prevents the constant-return blow-up
(~1e-17 residual variance). `emptySummary` returns nulls. Session bucketing documented: a session is an
IST day with ≥1 closed trade; **flat sessions are not imputed** (stated as a limitation — the candle
range is unavailable inside `computeSummary`). A `null` ratio under `DAILY_ANNUALIZED` is documented as
zero dispersion, not insufficient sample.

**DATA-001.** Provenance required (id, instrument, timeframe, source, date, timezone, adjustments,
limitations). SHA-256 via WebCrypto over canonical `t,o,h,l,c,v` rows (FNV-1a fallback); identical data
→ identical checksum, reordered data → different checksum (control asserts both). Per-session coverage
(375-bar grid), session window 09:15–15:30 IST, declared-holiday bars, within-session staleness,
zero volume, duplicates, ordering, invalid OHLC. Synthetic guard **throws** on `kind: "REAL"` with a
synthetic-looking source.

**CORR-001.** Full-prefix signals (windowed shortcut measured at 99.58–99.65% agreement → **rejected as
